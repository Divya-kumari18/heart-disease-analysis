# ❤️ Heart Disease Analysis

## 📌 About the Project
This project focuses on analyzing a heart disease dataset containing demographic, cardiovascular, exercise-related, and ECG-related patient information.
The notebook performs **data exploration, preprocessing, and analysis** to understand the characteristics of the dataset and prepare the data for further machine learning applications.

## 🎯 Objectives
* Explore the heart disease dataset.
* Understand the available patient and cardiovascular features.
* Perform data inspection and preprocessing.
* Analyze important health-related variables.
* Prepare the dataset for further machine learning analysis.
* Understand the target variable `HeartDisease`.

## 📊 Dataset
The dataset contains **918 patient records and 12 features**.

| Feature          | Description                           |
| ---------------- | ------------------------------------- |
| `Age`            | Patient age                           |
| `Sex`            | Patient sex                           |
| `ChestPainType`  | Type of chest pain                    |
| `RestingBP`      | Resting blood pressure                |
| `Cholesterol`    | Cholesterol level                     |
| `FastingBS`      | Fasting blood sugar indicator         |
| `RestingECG`     | Resting ECG result                    |
| `MaxHR`          | Maximum heart rate                    |
| `ExerciseAngina` | Exercise-induced angina indicator     |
| `Oldpeak`        | ST depression measurement             |
| `ST_Slope`       | Slope of the peak exercise ST segment |
| `HeartDisease`   | Target variable                       |
